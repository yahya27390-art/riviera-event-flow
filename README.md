# 🏛️ نظام حسابات قمة الريف للمناسبات والاحتفالات (Qemat Alreef Accounting)

نظام محاسبي وإداري سحابي متكامل ومخصص لإدارة قاعات المناسبات، حجوزات الأفراح والفعاليات، الحسابات المالية، الخزينة النقدية، المصروفات التشغيلية، والتحويلات البنكية ومطالبات العملاء عبر الواتساب.

---

## ✨ المميزات الرئيسية
* **واجهة مستخدم عصرية وفاخرة:** متوافقة بنسبة 100% مع أجهزة iPhone والجوال وشاشات سطح المكتب بدون لوحات جانبية معقدة.
* **إدارة الحجوزات والتقويم التفاعلي:** فحص فوري لمنع تعارض المواعيد، تبديل التقويم بين الهجري والميلادي، وطباعة العقود وسندات القبض.
* **الخزينة النقدية (الكاش):** متابعة المقبوضات والمصروفات النثرية ورصيد الخزينة اللحظي.
* **التحويلات البنكية:** مطابقة سندات التحويل مع البنوك المعتمدة وحسابات مدى.
* **المطالبات والتذكير بالواتساب:** إرسال رسائل تذكير بالمبالغ المتبقية للعملاء بضغطة زر واحدة.
* **المصروفات والتقارير المالية:** كشوف حسابات تفصيلية، مراقبة الإيرادات، ونسب الإشغال.
* **قاعدة بيانات Supabase (PostgreSQL):** ربط سحابي حقيقي وسريع مع أمان عالي ونسخ احتياطي فوري.

```bash

npm run dev

# بناء النسخة الإنتاجية
npm run build
```

## 🗄️ إعداد قاعدة البيانات (Supabase)
1. افتح مشروعك في **Supabase** وانتقل إلى **SQL Editor**.
2. انسخ محتوى الملف `supabase_schema.sql` واضغط **Run**.
3. أضف مفاتيح الربط في ملف `.env.local`:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
